# Contributing

1. Fork the repository and create a feature branch.
2. Follow the existing code style: type hints and **Google-style
   docstrings** for every public function (Args / Returns / Raises).
3. Add or extend unit tests for any change
   (`PYTHONPATH=src python -m unittest discover -s tests -v` must pass).
4. Open a pull request that references the issue it addresses.

Questions and ideas: open an issue on the tracker.
